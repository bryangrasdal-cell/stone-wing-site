# Stone Wing

**One governed AI workspace for Mac + Windows.**

Stone Wing brings multiple AI models, files, MCP tools, routing, Bridge-connected computers, and approval/governance controls into one desktop workspace.

## What it brings together

- Multiple supported AI providers
- Manual and automatic model routing
- Files and project context
- MCP-compatible tools
- Bridge-connected Mac and Windows computers
- Governance, approvals, and explicit authority boundaries
- Supported provider free-tier access where available
